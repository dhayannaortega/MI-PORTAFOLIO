# Mi Portafolio 

Sitio web profesional para entrega de la **Unidad 1: Fundamentos de los Lenguajes de Programación para la Web**. El sitio presenta mi perfil como estudiante de ingeniería de software mis proyectos y canales de contacto.

**Enlace web en GitHub Pages:** [https://dhayannaortega.github.io/MI-PORTAFOLIO/](https://dhayannaortega.github.io/MI-PORTAFOLIO/)

---

## Tecnologías utilizadas

Para este desarrollo se utilizaron las tecnologías base del frontend, programando desde Visual Studio Code sin utilizar librerías o frameworks adicionales:

* **HTML5:** Marcado semántico optimizado (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) y elementos interactivos nativos.
* **CSS3:** Estilos adaptativos basados en la filosofía *Mobile First*, arquitectura limpia mediante variables nativas (`:root`) y distribución de elementos con **Flexbox**.
* **JavaScript:** Control de comportamiento dinámico del DOM, escucha y gestión de eventos, junto con componentes interactivos personalizados como la calculadora web.
* **Control y Publicación:** Versionado de código con Git, almacenamiento en el repositorio de GitHub y despliegue automatizado en GitHub Pages.
